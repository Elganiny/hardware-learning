# Changelog: P00 Mini-Dashboard V1

## 1.0 (2026-11-21)

- First complete version: power LED (R1 270 Ω), push button with 10 kΩ pull-up, 3-pin JST PH connector.
- Footprints chosen: 0603 resistors and LED, 6 mm through-hole button, JST PH B3B-PH-K vertical.
- PCB 25 × 20 mm, 2 layers, GND zone on the bottom.
- ERC 0 / 0, DRC 0 / 0 (zones refilled after moving parts; button's duplicate pads joined).
